# M0: the physical-phone check

Run M0 on a real phone (not an emulator) after every change that touches app behavior, before calling it delivered, and once on the old build before you start, so a difference can be told apart from a phone that was already off. Compare **routes and outcomes** with the previous run, not wording, ranking or exact timing. Record results privately; they show your location, calendar and notifications.

Setup: a debug build (the script uses the debug `ask` command, the same agent route as typing on Home), set up as in the README, with Misura as home, notification access, app control, Shizuku, contacts/calendar/location granted and a working model key. One web-search provider selected.

```sh
export ANDROID_SERIAL=YOUR_PHONE_SERIAL
bash scripts/m0.sh /path/outside/the/repo/m0-$(date +%F)
```

The script runs every **auto** task, writes `results.md` (route, foreground app, screen text) and marks the checks it can decide. Read every row anyway. Then do the **hand** tasks below. When you add a feature, add its task here in the same pull request.
